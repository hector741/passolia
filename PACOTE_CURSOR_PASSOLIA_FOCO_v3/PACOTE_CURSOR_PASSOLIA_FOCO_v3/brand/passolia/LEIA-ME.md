# Passólia - ativos de identidade visual v1.0

Este pacote acompanha o Manual de Identidade Visual da Passólia, de 11/11/2026.

## O que usar

- SVG: arquivos vetoriais. O logotipo está convertido em curvas, com o acento correto.
- PNG: exportações raster transparentes do logo e ícones com fundo violeta.
- passolia-icone.svg: base quadrada; os recortes arredondados são aplicados pelo canal.
- passolia-icone-maskable.svg: versão com margem adicional para máscaras.
- passolia-simbolo-micro.svg e ícone de 16 px: versão óptica para o favicon pequeno.
- favicon.ico: contém imagens de 16, 32 e 48 px, com a versão óptica no tamanho de 16 px.
- icones_interface/: 12 desenhos SVG em grade 24, com currentColor.
- fontes/: Manrope variável, instâncias estáticas e licença SIL OFL 1.1.
- passolia-tokens.json e .css: valores de referência para implementação.

As duas imagens editoriais PNG foram geradas com IA como exemplos de fotografia e ilustração. Não retratam usuários reais e não devem ser apresentadas como depoimentos.

## Regras essenciais

Escrever Passólia com acento em ó. Preservar as proporções, o intervalo entre os dois trechos e a área de proteção. Não reconstruir a marca digitando o nome com outra fonte. No texto comum, usar a família Manrope conforme o manual.

Os tokens são uma base visual e não implementam uma aplicação. As telas e peças do manual são estudos de aplicação. Verificar acessibilidade na interface real e as exigências de exportação de cada canal no momento de publicação. O manual não substitui a pesquisa de marca e o registro no INPI.

Os SVG são a fonte geométrica para exportar novos tamanhos. As aproximações CMYK do manual não usam um perfil de impressão; produzir prova com a gráfica.
