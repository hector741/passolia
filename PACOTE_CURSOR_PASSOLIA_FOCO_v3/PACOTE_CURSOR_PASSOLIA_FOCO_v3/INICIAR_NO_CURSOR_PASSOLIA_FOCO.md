# Iniciar a Passólia com o módulo de foco

## O que este pacote entrega

O plano integral da plataforma e a nova especificação de foco, com pesquisa,
marca, critérios de aceite e instruções de continuidade. É material para o Cursor
implementar; não contém um aplicativo já pronto, credenciais ou testes de uso realizados.

## Se você já começou o aplicativo no Cursor

1. Continue na pasta do aplicativo que já está desenvolvendo.
2. Copie para essa pasta o novo prompt da raiz, esta instrução e `docs/foco/`.
3. Acrescente os dois arquivos `PESQUISA_MODULO_FOCO_PASSOLIA_2026-11-12` de
   `docs/pesquisa/`. Preserve código, migrações, regras e checkpoint atuais.
4. Se documentos antigos tiverem sido adaptados no seu projeto, não os substitua
   indiscriminadamente. O Cursor deve comparar e integrar os requisitos novos.
5. Cole o comando abaixo no modo Agent.

## Se ainda não começou

1. Extraia o ZIP e abra a pasta `PACOTE_CURSOR_PASSOLIA_FOCO_v3` no Cursor.
2. Selecione o modo Agent.
3. Cole o comando abaixo. A implementação começará pelas fundações necessárias.

## Comando inicial

```text
Leia INICIAR_NO_CURSOR_PASSOLIA_FOCO.md e integralmente
PROMPT_MESTRE_CURSOR_PASSOLIA_FOCO_v3.md.

Leia também o prompt global em docs/projeto, a pesquisa de foco em docs/pesquisa
e a matriz e o plano em docs/foco. Inspecione o repositório antes de alterar.

Desenvolva a Passólia integrando o módulo de foco definido nesses documentos.
Comece pela MP00, aproveite o que já funciona e implemente a primeira fatia
possível. Se a base estiver vazia, crie primeiro as fundações do plano global.

Priorize o ciclo manual de próxima ação, sessão ajustável, distrações,
pausa/retomada, redução e progresso parcial. Acrescente a IA opcional,
os avisos e a sincronização conforme dependências. Preserve os recursos
posteriores no plano e os testes FOC/EFOC na rastreabilidade.

Execute os checks pertinentes, registre resultados reais e mantenha
docs/CHECKPOINT.md atualizado. Avance nas etapas autorizadas sem reiniciar
o projeto nem descartar alterações existentes.
```

Não é necessário colar todos os documentos no chat: o Cursor lê os arquivos.
Chaves e segredos devem ser configurados no ambiente seguro do projeto,
sem colocá-los no prompt ou versioná-los.

## Onde encontrar cada material

- Prompt de integração: `PROMPT_MESTRE_CURSOR_PASSOLIA_FOCO_v3.md`.
- Plano integral: `docs/projeto/PROMPT_MESTRE_CURSOR_PASSOLIA.md`.
- Pesquisa completa nova: `docs/pesquisa/PESQUISA_MODULO_FOCO_PASSOLIA_2026-11-12.md` e PDF.
- Cobertura: `docs/foco/MATRIZ_DE_COBERTURA_E_ACEITE_FOCO.md`.
- Fases/retomada: `docs/foco/PLANO_E_CONTINUIDADE_FOCO.md`.
- Identidade visual: `brand/passolia/` e manual em `docs/referencia/`.

Os documentos de instrução da versão anterior foram preservados em
`docs/referencia/instrucoes_v2/`. Esta é a entrada atual para o pacote.
