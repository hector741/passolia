# Passólia — pacote de desenvolvimento para o Cursor

Versão 2.0 • 12/11/2026. Preparado para Hector Marinho.

O arquivo principal está em `docs/projeto/PROMPT_MESTRE_CURSOR_PASSOLIA.md`. É o prompt autossuficiente, pronto para copiar, colar ou anexar. O pacote é documentação para criar o aplicativo; não é o aplicativo implementado.

Nenhum segredo, conta contratada ou preço final é fornecido. O Cursor deve verificar versões e configuração do repositório real. Todos os testes do aplicativo começam como planejados; as verificações deste pacote são documentais. Arte gerada com IA no acervo de marca não é depoimento de cliente real. O estudo de nomes é histórico; o manual e os ativos finais prevalecem para a identidade visual.

Os arquivos de estado e código referidos no prompt deverão ser criados no projeto durante a implementação. Não são arquivos faltando neste pacote de especificação.
